RARE FOOTAGE KUMANA WEBSITE

This is a custom-coded, responsive single-page website.

IMPORTANT BEFORE PUBLISHING:
1. Replace the demo wildlife images with your own photos if you prefer.
2. Replace the Facebook button URL in index.html with your actual Rare Footage Kumana Facebook Page link.
3. Replace the email address placeholder with your real contact email, or remove the email button.
4. Add your real YouTube video link/embed when you have one.

FREE PUBLISHING OPTION (GitHub Pages):
1. Sign in at https://github.com/ in Safari.
2. Create a new public repository, for example: rare-footage-kumana.
3. Upload index.html from this folder to the repository's main/root folder.
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait a few minutes for the public site URL to appear on the Pages screen.
